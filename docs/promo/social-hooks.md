# LaunchClip Social Hooks

Use these as draft starting points after a real packet has been generated and
reviewed.

## X / Bluesky

- `launchclip` turns repo evidence, demo proof, and a maintainer angle into a
  reviewable launch packet before anything gets posted.
- The best OSS promo artifact is the one you can inspect: command proof,
  captions, review notes, and a clear approval boundary.
- Demo first, publish later: `launchclip run` creates the packet, reviewers keep
  control of the message.

## LinkedIn

Small OSS projects often have working demos but no repeatable promotion flow.
`launchclip` keeps that process local-first: gather repository evidence, attach
demo proof, draft review notes and captions, then decide what is ready for a
public channel.

## Short Video Hook

Start with the terminal:

> "Before an OSS tool gets promoted, I want the evidence, captions, and review
> handoff in one local folder."

Then show `launchclip doctor`, `launchclip run`, the generated `REVIEW.md`, and
the explicit `production-render --approve` boundary.
