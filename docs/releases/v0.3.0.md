# LaunchClip 0.3.0

**Motion that is checked before you see it, more to draw with, and the first release on npm.**

0.3.0 is the first version published to npm. It carries everything since 0.2.0, which was tagged in the changelog but never published.

## What's new

- **A motion check before the render.** A plan fails if an entrance eases in, an exit eases out, something slides at one speed, an exit is slower than its entrance or a cascade runs over two seconds. Each finding names the scene, the element and the fix.
- **Fuller motion grammars.** Every grammar now sets how duration grows with travel distance, how much shorter an exit is than its entrance, how far children trail their parent, parallax by depth and how far the frame dims behind the hero.
- **Springs chosen by feel.** Pick a spring by how long it looks and how much it bounces.
- **Exploded-view scenes.** One object drawn as an isometric machine of solid parts that comes apart, holds with its labels and snaps back. A server, a phone and a battery are built in, or give it a parts list.
- **Nineteen backdrop plates**, drawn in code and lit in your brand's colours.
- **Hand-drawn marks and a light leak.** A title can underline, circle or box its highlighted words, and a cut can carry a warm light leak.
- **Openverse in research.** Openly licensed images from Flickr, museums and other collections, limited to licences that allow commercial use and modification, with no key.
- **Remotion 4.0.543**, with fixes for renders that hung after a browser crash or a failed download.
- **HyperFrames 0.7.111**, with its sound matched to Remotion's level, and `onnxruntime-node` 1.31.1. One known advisory remains in the dependencies (`sharp`, with no fix upstream).

## Changed, and worth knowing before you upgrade

- **Three backdrop plates are removed:** `strands`, `hex-shell` and `starfield`. A stored plan that names one needs another plate.
- **Remotion peers moved to `^4.0.543`.** An app that renders with `@launchclip/remotion` needs every Remotion package on that version.

The full list is in the [CHANGELOG](../../CHANGELOG.md#030---2026-11-16).

## Install

```bash
npm install --global launchclip
launchclip skills install --agent claude    # or: --agent codex
```

Then ask your agent: `/launchclip-create-video-remotion Make a 60-second landscape launch video for my product using the files in ./assets`

To build on the engine in your own app:

```bash
npm install --save-exact @launchclip/core @launchclip/remotion
```

The four packages (`launchclip`, `@launchclip/core`, `@launchclip/remotion`, `@launchclip/engine`) share one version number and are published from one commit. While the version is `0.x`, a minor release may break the API, so pin exact versions.

Requirements: Node.js 22+ and FFmpeg. The first run downloads the renderer's browser and the offline voice model (about 325 MB), so the first video takes roughly 10–15 minutes longer; later videos start straight away.

See the [README](../../README.md) and the [guides](../guide/README.md).
