# make-vs-skill parity fixture pair

Two small finished projects from one made-up news brief, for the parity
harness (`eval/make-parity.mjs`, `npm run eval:make-parity`):

- `make/`: the failure the RFC describes. Mostly words on a backdrop, a card
  held for 17 seconds, a repeated card and a hedging script.
- `skill/`: the same brief with an agent directing. Varied modules, the
  source on screen, a firm script and a critic that says ship.

Each has only what the harness reads: `storyboard.json`, `NARRATION.json`
and `qa/critic.json`. The company and its numbers are invented.
